# 🏥 Hospital-AI | Nalam Health AI

AI-powered healthcare assistant designed to simplify patient healthcare services through intelligent symptom analysis, doctor recommendations, appointment management, and online consultations.

## 📌 About the Project

Hospital-AI is an AI-based healthcare assistance system that helps patients describe their symptoms, receive preliminary health guidance, identify suitable medical specialists, and book doctor appointments.

The system provides a digital platform for patients and doctors with appointment approval workflows and online consultation support.

## ✨ Features

- 🩺 AI-based symptom analysis
- 👨‍⚕️ Doctor recommendations based on symptoms
- 📝 Patient information collection and management
- 📅 Appointment booking and scheduling
- 🔔 Appointment status tracking
- ✅ Doctor appointment approval and rejection
- 💬 Patient-doctor interaction
- 📹 Online video consultation
- 🚨 Emergency symptom awareness and emergency guidance

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Frontend:** Streamlit
- **Backend:** FastAPI
- **Database:** Microsoft SQL Server
- **AI/ML:** Artificial Intelligence & Machine Learning
- **Communication:** WebRTC

## 🔄 Workflow

1. Patient enters personal details.
2. Patient describes symptoms and uploads an image if required.
3. AI analyzes the submitted information and provides preliminary guidance.
4. The system recommends an appropriate medical specialist.
5. Patient selects a doctor and available appointment slot.
6. Appointment request is submitted.
7. Doctor accepts or rejects the appointment.
8. Patient receives the appointment status.
9. Online consultation is provided through video communication.

## 🎯 Project Objective

To improve healthcare accessibility and simplify the patient-doctor appointment process using Artificial Intelligence and modern web technologies.

## ⚠️ Disclaimer

This application is designed for healthcare assistance and educational purposes only. AI-generated symptom analysis is not a medical diagnosis. Patients should consult qualified healthcare professionals for medical advice. In emergencies, contact local emergency services.
